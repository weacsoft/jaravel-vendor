Wire 组件系统 全新重写

类似 Laravel Livewire 的全页组件框架 — 一次渲染，局部更新

概述

Wire 模块在 v2.0 中进行了彻底重构，废除了旧版 WireService 和 WireResponse， 引入统一的 WireController 抽象基类，实现类似 Laravel Livewire 的"一次渲染，局部更新"能力。

核心变化：Component 组件和 Navigation 导航功能完全统一到一个 WireController 基类。 用户只需继承 WireController 并实现 render()，即可获得首屏渲染、局部更新、临时组件下发等全部能力。

快速开始

1. 创建 Wire 控制器

import com.weacsoft.jaravel.vendor.wire.WireController;
import com.weacsoft.jaravel.vendor.wire.WireView;
import com.weacsoft.jaravel.vendor.http.controller.request.Request;
import com.weacsoft.jaravel.vendor.http.controller.response.Response;
import org.springframework.stereotype.Controller;

@Controller
public class TodoController extends WireController {

    // 公共字段自动暴露给模板
    public String query;
    public List<Todo> items;

    // 必须实现：声明要渲染的模板
    @Override
    protected WireView render() {
        return wireView("todos.item")
                .extends("layouts.app")
                .section("content")
                .title("待办事项");
    }

    // 可选：初始化（仅首屏调用）
    @Override
    protected void mount(Map<String, Object> params) {
        query = "";
        items = Todo.self().newQuery().get().toObjectList();
    }

    // 可选：自定义布局
    @Override
    protected String getLayout() {
        return "layouts.app";       // 直访时的父模板
    }

    @Override
    protected String getWireLayout() {
        return "layouts.dialog";   // wire 触发时的父模板（Dialog 等）
    }

    // wire action：可被 wire:click / wire:submit 调用
    public void addTodo() {
        Todo todo = new Todo();
        todo.setTitle(query);
        todo.save();
        items.add(todo);
        query = "";
    }

    public void deleteTodo(int index) {
        items.remove(index);
    }
}

2. 注册路由

// 同一 URL 对接 index（首屏）和 update（局部更新）
Route.get("/todos", "TodoController::index");
Route.post("/todos", "TodoController::update");

3. 模板中使用

<!-- todos.item.jblade -->
@extends('layouts.app')
@section('content')
    <div>
        <h2>待办事项</h2>
        <form wire:submit="addTodo">
            <input type="text" wire:model="query" />
            <button type="submit">添加</button>
        </form>

        <ul>
            @foreach($items as $index => $item)
            <li>
                {{ $item->title }}
                <button wire:click="deleteTodo($index)">删除</button>
            </li>
            @endforeach
        </ul>
    </div>
@endsection

WireController API

必须实现

方法说明
protected abstract WireView render()声明要渲染的模板及布局配置

可选覆盖

方法默认行为说明
mount(Map)空实现仅首屏调用一次，用于加载初始数据
fill(Map)反射赋值批量赋值 public 字段
getLayout()返回 null直访场景的父模板
getWireLayout()同 getLayout()wire 触发场景的父模板（Dialog 等）

框架默认实现

方法HTTP说明
index(Request)GET首屏渲染：mount → 收集属性 → fill → render → 注入 wire assets
update(Request)POST局部更新：decode snapshot → merge params → invoke action → 渲染 sections → JSON

WireView 链式 API

protected WireView render() {
    return wireView("todos.item")           // 模板名
            .extends("layouts.app")          // @extends 父模板
            .section("content")              // @section 名称
            .with("extra", extraData)         // 额外变量
            .title("待办事项");                // 页面标题
}

临时组件下发

在 wire action 中通过 wire().component() 下发临时组件：

public void save() {
    // ...保存逻辑...
    wire().component("toast", Map.of(
        "message", "保存成功",
        "type", "success"
    ));
}

注册临时组件

# application.yml
jaravel:
  wire:
    components:
      toast: components.toast       # 组件名 → 模板名
      confirm: components.confirm

jblade 新指令

@assets / @endassets

在模板中收集 CSS 资源，自动注入到 </head> 前：

@assets('css/app.css')
@assets('css/theme.css')
@endassets

@script / @endscript

在模板中收集 JS 资源，自动注入到 </body> 前：

@script('js/app.js')
@script('js/util.js')
@endscript

wire.js 前端指令

指令说明
wire:click="actionName"点击触发指定 action
wire:submit="actionName"表单提交或按钮提交触发指定 action
wire:model="fieldName"输入框双向绑定
data-wire-input="fieldName"自定义输入绑定

wire:submit 支持 button

wire:submit 不仅支持 <form> 标签，还支持 <button> 和 <input type="submit">。 当 button 内有 wire:submit 时，框架自动拦截其父表单的提交事件。

安全性

Snapshop 签名

Wire 每次更新时会对页面状态（所有 public 字段）进行 HMAC-SHA256 签名， 确保客户端无法篡改状态数据。签名验证失败时返回 403 错误。

@WireLocked

使用 @WireLocked 注解标记不允许客户端修改的字段：

public class UserController extends WireController {
    @WireLocked
    public Long userId;    // 客户端无法修改
    public String name;    // 客户端可修改
}

参数类型

安全提示：所有通过 wire action 传递的参数均视为 String 类型。 框架不进行类型推断，避免 XSS 等安全风险。需要其他类型时在 action 方法中手动转换。

错误项目参考实现

error 项目的 AdminController 展示了完整的迁移过程： 查看源码

// 关键设计：保留 $setting 变量，兼容原有 item.jblade 模板
@Controller
public class AdminController extends WireController {
    public Admin setting;

    @Override
    protected WireView render() {
        return wireView("mdui.admin.admin.item")
                .extends("layouts.mdui.form")
                .with("setting", setting)
                .title(setting != null ? "修改管理员信息" : "新增管理员信息");
    }

    @Override
    protected String getLayout() {
        return "layouts.mdui.form";
    }

    @Override
    protected String getWireLayout() {
        return "layouts.mdui.form.dialog";
    }

    @Override
    protected void mount(Map<String, Object> params) {
        if (params.get("id") != null) {
            setting = Admin.self().find(params.get("id").toString()).toObject();
        } else {
            setting = new Admin();
        }
    }

    public void save() {
        if (setting == null) setting = new Admin();
        setting.save();
        wire().component("toast", Map.of("message", "保存成功", "type", "success"));
    }

    // 传统列表和删除方法保持不变
    public Response list(Request request) { ... }
    public Response delete(Request request) { ... }
}
